# Football Club Elo

This repository is a cleaned-up version of an old football analysis folder, narrowed to one maintainable project: downloading English club history from ClubElo, joining it to manager-tenure data from Wikipedia, and exploring the result in a small Shiny app.

Repo: https://github.com/skthewimp/football

The live data source still appears to be available as of May 10, 2026:

- `clubelo.com` for current ratings and historical club timelines
- Wikipedia manager-list pages for Premier League and Championship clubs

## What is in the repo

- `scripts/refresh_club_elo.R`: downloads ClubElo histories for English clubs
- `scripts/build_manager_elo.R`: scrapes manager lists and joins them to Elo histories
- `scripts/refresh_all.R`: runs both refresh steps
- `scripts/download_epl_results.R`: downloads Premier League match results from Football-Data.co.uk and derives points progressions
- `scripts/plot_epl_2025_26_points_progression.R`: plots the 2025-26 points race by calendar date
- `scripts/plot_epl_2025_26_points_by_matchday.R`: plots the 2025-26 points race by matches played
- `scripts/plot_epl_2025_26_points_by_matchday_faceted.R`: plots one 2025-26 matchday panel per club with short season-story subtitles
- `app/app.R`: Shiny app for browsing a club's Elo history by manager tenure
- `data/raw/`: raw ClubElo snapshot generated by the refresh script
- `data/derived/`: joined manager/Elo outputs and derived Premier League points tables
- `legacy/`: original scripts and unrelated old analysis kept for reference
- `archive/local-only/`: large local artifacts that should not go to GitHub

## Refresh the data

```bash
Rscript scripts/refresh_all.R
```

This writes:

- `data/raw/clubelo_eng.rds`
- `data/derived/clubelo_eng_latest.csv`
- `data/derived/manager_elo_eng.rds`
- `data/derived/manager_elo_eng_latest.csv`

The current snapshot generated during the latest refresh ends at `2026-05-31` in ClubElo's `From` dates, with the repo refreshed on `2026-05-20`.

## Premier League results and points charts

Premier League match results come from Football-Data.co.uk's `E0.csv` files:

- Source pattern: `https://www.football-data.co.uk/mmz4281/{season_code}/E0.csv`
- Current seasons downloaded: `2020-21` through `2025-26`
- Season codes used: `2021`, `2122`, `2223`, `2324`, `2425`, `2526`

Download and derive the results data first:

```bash
Rscript scripts/download_epl_results.R
```

This writes:

- `data/raw/epl_results_2020_21.csv` through `data/raw/epl_results_2025_26.csv`
- `data/raw/epl_results_2020_21_to_2025_26.csv`
- `data/derived/epl_points_progression_2020_21_to_2025_26.csv`
- `data/derived/epl_2025_26_points_progression.csv`

Then render charts from the derived data:

```bash
Rscript scripts/plot_epl_2025_26_points_progression.R
Rscript scripts/plot_epl_2025_26_points_by_matchday.R
Rscript scripts/plot_epl_2025_26_points_by_matchday_faceted.R
```

These write:

- `docs/figures/epl-2025-26-points-progression.png`: cumulative points by calendar date
- `docs/figures/epl-2025-26-points-by-matchday.png`: cumulative points by matches played
- `docs/figures/epl-2025-26-points-by-matchday-faceted.png`: one matchday panel per club

As of the latest download on `2026-05-24`, Football-Data has `370` completed 2025-26 Premier League matches through `2026-05-19`, so the 2025-26 charts are season-to-date rather than final-table charts.
